SECTION 06

swap_horiz 6. API Request & Error Handling Flow

1. Payload Preparation Client Side

Encodes the input image into a clean base64 string, strips data URI headers, constructs inline data contents, and appends system prompt instructions requesting structured JSON output.

2. HTTPS POST Dispatch Network Transport

Dispatches POST request to https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={apiKey} with an AbortController 14s safety timeout.

3. Quota Exception Handling & Model Failover Failover Engine

If the server returns HTTP 429 (Quota Exceeded) or network failure, the client catches the exception and immediately invokes the next candidate model in the fallback chain (gemini-2.5-flash-lite → gemini-2.5-pro). If all configured models fail, displays a clean notice offering a retry or offline demonstration report.

SECTION 07

warning 7. System Limitations

  • API Free-Tier Rate Limits

    Public Gemini API keys are subject to shared free-tier RPM/TPM rate limits, requiring fallback mechanisms during peak traffic.

  • Browser Storage Quotas

    HTML5 LocalStorage is capped per domain (~5MB–10MB), requiring thumbnail downscaling (500px JPEG) for saved history entries.

  • Client Canvas Memory Usage

    Processing 4K images on client Canvas 2D context consumes temporary browser RAM during pixel luma array iteration.
